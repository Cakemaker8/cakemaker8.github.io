Tools

This page features the tools that I have created, which are listed below.


Graduate School Finder: Allows for a user to find and save schools based on their field and degree type. Specifically meant for graduate schools, and helps to reduce the effort needed to find programs in a specific field. View the website here.

CO:E33 Save Analyzer: This project shows what items a user has collected in the video game Clair Obscur: Expedition 33. It shows the music records, journals, pictos, weapons, hairstyles, and outfits collected, the wiki page, and the level (if applicable). This tool creates an easy way to see what is needed, as it can be accessed fully online, and requires no downloads. Can be accessed on this website here.

Algae Monitoring Project: Created for my senior design team, this project features the data collected by the Algae Detection Boat. View the website here.

Hollow Knight: Silksong Content Extractor: A Python program developed to extract sprites, textures, audio, and videos from the video game Hollow Knight: Silksong. It also features a way to view sprites from the custom sprite maps. Download the Python program here, and the pip dependencies here.
