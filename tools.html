Tools

This page features the tools that I have created, which are listed below (proper thumbnails will be here eventually).

Graduate School Finder: An online tool that allows for a user to find and save schools based on their field and degree type. Specifically meant for graduate schools, and helps to reduce the effort needed to find programs in a specific field.

CO:E33 Save Analyzer: A website that shows what items a user has collected in the video game Clair Obscur: Expedition 33. It shows the music records, journals, pictos, weapons, hairstyles, and outfits collected, the wiki page, and the level (if applicable). This tool creates an easy way to see what is needed, as it can be accessed fully online, and requires no downloads.

Algae Monitoring Project: A website created for my senior design team, this project features the data collected by the Algae Detection Boat.

Hollow Knight: Silksong Content Extractor: A Python program developed to extract sprites, textures, audio, and videos from the video game Hollow Knight: Silksong. It also features a way to view sprites from the custom sprite maps. Download the Python program here, and the pip dependencies here. The notes that I wrote about the project can be viewed here and here (not organized, and extremely sloppy).

Hollow Knight: Silksong Save Analyzer: This website shows what items a user has collected in the video game Hollow Knight: Silksong. The plan is for it to show every single item in the game and a link to the wiki page; however, it does not include everything at this current point. It also allows for the user to download the save file as a json file, edit it, reupload back to the website, and download as a dat file, as a dedicated save editor will not be created.
