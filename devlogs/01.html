Random Updates (July 2026)

Huh, I am actually making a devlog for once.

Well, welcome to this devlog! There has been a lot of work on this website since I first made it. Let me go through updates on the website:

  • Home page: this page contains some basic info about me, as well as the projects that I am working on
  • Tools: this page contains links to access the tools available on this website
  • Games: this page contains links to any games that I have worked on (usually to itch.io)
  • Devlog: this page contains links to the devlogs I have made (which will hopefully be more over time)

Now for more important stuff, the tools:

  • Graduate school finder: it is mostly functional, with the ability to find schools and save them; however, I don't think I will work much more on it, unless I find a reason to
  • E33 save file parser: it currently shows if you have all items that can show up in the inventory, the level (if applicable), and a link to the Wiki page
  • Algae monitoring project: this was for school, as part of my senior design class; I will not be working on it anymore

I think I might redo the tools page. I like how all the other pages look, but I am debating if this website will have more quantity or quality, which leads to some of the projects that I have been working on. Here is a quick overview:

Silksong save file parser: I have everything ready to work on it, I just need to actually make it. It runs pretty identical to the Clair Obscur parser, so it's honestly just a lot of boring data entry (I need to get all the json files made for it). This parser will also be able to save as a json file, so that you can modify your own save, and be able to upload back to the website to put in the right format for the game. On the website, it will contain all the necessary information to 100% the game, get all achievements, and get all collectables; basically, it will show your progress for every single thing in the game. Not difficult to make, just time consuming and boring, and something that I might save for when the school year starts. I am not actively working on it, but I would like to finish it, I am just saving it for when I need a mindless activity to do. Maybe around September 2026 it will be finished, depending on how school goes.

Silksong content parser: I have spent a fair bit of time on this, and unfortunately it is all bad news. The only way that I could view the sprites for the game was through UnityPy. This made me want to make a content viewer for others, as it is not user-friendly for most people in python. I could view the sprites, textures, and audio through UnityPy, and just needed to make a wrapper for it all. However, this is where the issues begin. I want to make it available on this website, and not through an application, so that pretty much anyone can access it. This requires Web Assembly, which could not run UnityPy due to some of its dependencies. I could just decode the asset files, but honestly, no. I have considered just making it an application instead, but that ruined my motivation for the project, as the whole point of it was to run on the web; tkinter would not work either, and I am not that familiar with building UIs in python. I could learn, but it is more time that I would have to spend on something that I am not sure of. I spent a lot of time on this project, and hate to stop now, but this project might just be on hold. I did not really enjoy Silksong that much, and do not like to work with Unity, but I do absolutely love the art and music of the game.

E33 save file parser: Onto some good news, I figured out more of how the inventory works. This now makes me want to make it so that you can add any item you want, or modify any item already in the inventory. I still need to figure out how to do this for weapons and pictos, as well as being able to see if you have mastered a picto. I also want to see if I can figure out more of the save file, so that it can show achievement progression and perhaps various tints acquired. The only reason why I have not worked on this is because I really wanted to do the Silksong stuff first; however, I would much rather just keep adding to this project (I do want more stuff on this website though). My E33 hours are about to overtake my Godot and BG3 hours; that game is a ton of fun.

Chess in Godot: Godot is the best game engine, and I have done a lot of work in it. I cannot figure out what I want to make in it, as I want more tools on this website, but I want to try getting a chess engine running in Godot, then having it run through HTML. There really isn't much else to this, as I have not worked on it yet, but it sounds like fun.

Wow, that was a lot. I'm just rambling at this point. Maybe it's time to start working on one of those projects. Maybe redesigning this website.
