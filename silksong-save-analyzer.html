Hollow Knight: Silksong Save Analyzer

Welcome to the Hollow Knight: Silksong save file analyzer! Here you can upload a save file (either as .dat or .json), and view what items you have acquired. You can also export the save file either as a .dat file or a .json file, edit it, and reupload here to edit the save file, as an editor will not be created for this tool. The save file can be found at Users/[username]/AppData/LocalLow/Team Cherry/Hollow Knight Silksong/[filename], where [username] is the name of your computer's user, and [filename] is user#.dat, where # can be 1-4.

This tool is a work in progress, and the following items will be included at a future date: journals, quests, links to the wiki, better organization, and possibly more items (depending on what I need for my own save). Some items may be incorrectly listed in this parser.
